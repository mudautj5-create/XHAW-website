Dropdown menus. Packages and Activities now open a dropdown listing each item with its price. It works with hover, click or keyboard, and Esc closes it. On phones they are collapsible groups.


Tables.

Compare tables: packages.html and activities.html each have a compare table.
Quick facts: every detail page has a Quick facts table.
Booking page: the cart is now a table with a subtotal row, and there is a Discount guide table.
Quote: the quote itself shows an itemised table.

Error handling.

Form errors: the forms show messages under each field instead of browser pop-ups, for example “Enter a valid number, e.g. 071 000 0000”. They also show a summary banner and focus the first problem.
Empty booking: generating a quote with an empty booking is blocked with a clear message.
Maximum quantity: there is a warning at the 25-item maximum.
Fallbacks: a broken image gets a placeholder, and the download is guarded against failure.
Browser and files: you get a warning if the browser blocks saved selections or if data.js doesn’t load.
